Vercel ile Ücretsiz Deploy: Adım Adım Rehber

VercelCI/CDGitHub

Neden Vercel?

Statik siteler ve frontend projeleri için Vercel, en hızlı ve en kolay deploy çözümü. Ücretsiz plan: sınırsız deploy, HTTPS, global CDN, custom domain.

Adım 1: GitHub Deposu Hazırla

Projenizi GitHub'a push'layın. Vercel, repo'nuzu doğrudan okuyacak:

git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/user/repo.git
git push -u origin main

Adım 2: Vercel'e Bağlan

vercel.com'a gidin ve GitHub hesabınızla giriş yapın. "New Project" butonuna tıklayıp repo'nuzu seçin.

  • Framework Preset: "Other" (statik site için)
  • Build Command: Boş bırakın
  • Output Directory: ./ (root)

Adım 3: Custom Domain

Vercel dashboard'da "Domains" sekmesine gidin. Domain'inizi ekleyin ve DNS ayarlarını yapın:

Tip: A     | Ad: @    | Değer: 76.76.21.21
Tip: CNAME | Ad: www  | Değer: cname.vercel-dns.com

DNS yayılımı genellikle 10 dakika ile 24 saat arasında sürer. Vercel otomatik olarak SSL sertifikası oluşturur.

Adım 4: Otomatik CI/CD

Artık her git push otomatik deploy tetikler:

  1. Kod'u değiştirin
  2. git add . && git commit -m "update" && git push
  3. Vercel otomatik build + deploy yapar (~15 saniye)
  4. Preview URL ile test edin, sonra production'a promote edin

Bonus: Environment Variables

API key'ler gibi hassas değerler için Vercel dashboard'daki "Environment Variables" bölümünü kullanın. Asla repo'ya commit etmeyin!

Sonuç

Bu portfolyo sitesi tam olarak bu yöntemle deploy edildi: GitHub push → Vercel otomatik build → erdiocal.com'da canlı. Toplam maliyet: 0₺.

Free Deployment with Vercel: Step-by-Step Guide

VercelCI/CDGitHub

Why Vercel?

For static sites and frontend projects, Vercel is the fastest and easiest deploy solution. Free plan: unlimited deploys, HTTPS, global CDN, custom domain.

Step 1: Prepare GitHub Repository

Push your project to GitHub. Vercel will read your repo directly:

git init
git add .
git commit -m "Initial commit"
git remote add origin https://github.com/user/repo.git
git push -u origin main

Step 2: Connect to Vercel

Go to vercel.com and sign in with your GitHub account. Click "New Project" and select your repo.

  • Framework Preset: "Other" (for static sites)
  • Build Command: Leave empty
  • Output Directory: ./ (root)

Step 3: Custom Domain

Go to "Domains" tab in Vercel dashboard. Add your domain and configure DNS:

Type: A     | Name: @   | Value: 76.76.21.21
Type: CNAME | Name: www | Value: cname.vercel-dns.com

DNS propagation typically takes 10 minutes to 24 hours. Vercel automatically generates an SSL certificate.

Step 4: Automatic CI/CD

Now every git push triggers an automatic deploy:

  1. Make your changes
  2. git add . && git commit -m "update" && git push
  3. Vercel auto-builds and deploys (~15 seconds)
  4. Test with preview URL, then promote to production

Bonus: Environment Variables

For sensitive values like API keys, use the "Environment Variables" section in Vercel dashboard. Never commit them to the repo!

Conclusion

This portfolio site was deployed exactly this way: GitHub push → Vercel auto-build → live on erdiocal.com. Total cost: $0.
